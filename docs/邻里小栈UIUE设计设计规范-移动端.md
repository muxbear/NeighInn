## 1. 设计原则与理念

### 1.1 品牌调性

> **「邻里小栈」是邻里间的温暖市集**——每一次滑动都是一次邻里间的招呼，每一件物品都带着生活的温度。

| 维度 | 描述 | 设计体现 |
| --- | --- | --- |
| 温暖 | 如家般亲切、安心、无距离感 | 柔和色彩、圆润造型、温暖光晕、微拟人动效 |
| 可信 | 真实身份、真实邻里、真实交易 | 认证徽章、实景照片、实名认证标识、透明距离 |
| 高效 | 5 分钟完成一次交易决策 | 信息层级清晰、路径最短、操作零学习成本 |
| 节制 | 不打扰、不诱导、不骚扰 | 克制的推送、无过度装饰、尊重用户选择 |

### 1.2 核心设计原则

| 编号 | 原则 | 说明 | 案例 |
| --- | --- | --- | --- |
| DP-01 | **以邻里为中心** | 所有设计围绕"同小区邻里"这一核心场景，强化"远亲不如近邻"的情感连接 | 首页以小区为单位组织信息、距离与耗时是首要信息要素 |
| DP-02 | **所见即所得** | 物品照片即实物，距离即真实距离，信用即真实信用 | 无美颜过度处理、距离精确到 10 米级、AI 质检结果可视化 |
| DP-03 | **低认知成本** | 50 岁以上业主也能轻松使用，所有操作路径 ≤ 3 步到达核心功能 | 大字号、大按钮、口语化文案、图标直白 |
| DP-04 | **交易安全感** | 每一步关键操作都让用户感到安心，资金操作全链路透明 | 担保支付状态可视化、验货确认双按钮、纠纷处理流程透明 |
| DP-05 | **克制的社交** | 社交功能服务于交易，不做过度社交化干扰 | 留言默认折叠、好友数量上限、私信入口收敛 |
| DP-06 | **渐进式披露** | 复杂信息分层次呈现，默认只展示最关键的信息 | 详情页先展示图片+价格+距离，再展开描述+留言+卖家信息 |

### 1.3 信息架构总览

```
Tab 栏（底部 5 Tab）
├── 首页（本小区商店）
├── 附近（邻近小区）
├── 发布（+）
├── 消息
└── 我的
```

> **设计决策**：发布入口居中突出（圆形大按钮 + 温暖渐变背景），符合"把闲置物流动起来"的产品核心。

## 3. 布局与栅格

### 3.1 页面结构

```
┌─────────────────────────────┐
│       状态栏 (System)        │
├─────────────────────────────┤
│   导航栏 (title + right)     │
├─────────────────────────────┤
│                             │
│       页面内容区域           │
│                             │
│                             │
├─────────────────────────────┤
│   底部 Tab 栏 (5 items)     │
└─────────────────────────────┘
```

### 3.2 栅格系统

- **内容宽度**：全屏宽减 32dp 左右边距（即左右各留 16dp）
- **栅格列数**：12 列，列间距 8dp
- **断点**：
  - 小屏（≤ 360dp）：左右边距 12dp
  - 标准屏（361–420dp）：左右边距 16dp
  - 大屏（≥ 421dp）：左右边距 24dp，内容居中限宽 400dp

### 3.3 导航栏

| 元素 | 规范 |
| --- | --- |
| 高度 | 44dp + 状态栏高度 |
| 背景 | 白色（`colorBgCard`），滚动时可透明渐变 |
| 标题 | `textTitle`(20dp, Semibold)，居中 |
| 返回按钮 | 左侧 44×44dp 点击区域，图标 24×24dp |
| 右侧操作 | 最多 2 个图标按钮，间距 8dp |
| 大标题模式 | 首页使用大标题模式（`textDisplay`/`textHeadline`），滚动后自动缩小为标准标题 |

### 3.4 底部 Tab 栏

| 元素 | 规范 |
| --- | --- |

## 4. 交互与动效

### 4.1 动效原则

| 编号 | 原则 | 说明 |
| --- | --- | --- |
| ME-01 | **自然流畅** | 使用缓动曲线模拟物理运动，避免线性机械运动 |
| ME-02 | **适度克制** | 动效服务于信息传达，不为动而动；单页面同时动效 ≤ 2 个 |
| ME-03 | **性能优先** | 优先使用 `transform` 和 `opacity` 实现动画，避免布局重排 |
| ME-04 | **用户可控** | 动效时长 ≤ 300ms；支持系统"减弱动态效果"设置 |

### 4.2 缓动曲线

| 名称 | CSS 值 | 用途 |
| --- | --- | --- |
| `easeOut` | `cubic-bezier(0.22, 1, 0.36, 1)` | 通用出场、弹出、过渡 |
| `easeInOut` | `cubic-bezier(0.45, 0, 0.55, 1)` | 通用双向过渡、开关切换 |
| `easeIn` | `cubic-bezier(0.64, 0, 0.78, 0)` | 入场、收起 |
| `spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 发布按钮弹跳、点赞反馈 |

### 4.3 标准动效规范

| 场景 | 时长 | 缓动 | 说明 |
| --- | --- | --- | --- |
| 页面切换（推入） | 300ms | easeOut | 从右向左滑入 + 轻微缩放 |
| 页面切换（弹出） | 300ms | easeOut | 从左向右滑出 |
| 底部弹窗弹出 | 280ms | spring | 从底部滑入 + 背景遮罩渐入 |
| 底部弹窗收起 | 240ms | easeIn | 向下滑出 + 遮罩渐出 |
| 模态弹窗弹出 | 220ms | spring | 中心缩放 + 淡入 + 遮罩渐入 |
| 下拉刷新 | 即响应 | — | 释放即触发，loading 不延迟 |
| 按钮按下反馈 | 100ms | easeInOut | 缩放至 0.96 + 主色加深 |
| 点赞/收藏 | 200ms | spring | 图标弹跳 + 粒子扩散 |
| 图片放大预览 | 250ms | easeOut | 从缩略图位置缩放放大 |
| 加载骨架屏 | 1.5s 循环 | linear | 微光扫过效果 |

### 4.4 手势交互

| 手势 | 场景 | 反馈 |
| --- | --- | --- |
| 点击 | 所有可交互元素 | 视觉：按下态颜色加深/缩放 0.96；触觉：短振动（支持的设备） |
| 长按 | 收藏、删除、置顶等二级操作 | 触觉反馈 + 弹出操作菜单 |
| 滑动（水平） | 商品图轮播、卡片滑出删除 | 跟手流畅、惯性滚动 |
| 滑动（垂直） | 列表滚动、下拉刷新、上拉加载 | 回弹效果（iOS）、边缘波纹（Android） |
| 双击 | 商品图快速放大、点赞 | 触觉反馈 + 动画 |
| 拖拽 | 排序、移动 | 实时跟手 + 目标区域高亮 |
| 捏合 | 图片缩放 | 跟手缩放，支持双击还原 |

### 4.5 页面转场

| 转场类型 | 实现 | 视觉效果 |
| --- | --- | --- |
| Push（进入详情） | 水平滑动 | 新页面从右侧 30dp 处滑入至屏幕，旧页面左侧 10dp 淡出 |
| Pop（返回） | 水平滑动 | 旧页面向右滑出，新页面淡入 |
| Present（模态） | 垂直 + 缩放 | 从底部缩放弹出，背景遮罩渐入 |
| Dismiss（关闭模态） | 垂直 + 缩放 | 向下缩排放回，遮罩渐出 |
| Tab 切换 | 淡入淡出 | 内容区域交叉淡入淡出，300ms |
| 根页面切换 | 淡入 + 微缩放 | 整页淡入 + 0.98 → 1.0 缩放 |

## 5. 组件库规范

### 5.1 按钮

#### 5.1.1 主要按钮（Primary）

| 属性 | 规范 |
| --- | --- |
| 背景 | 品牌渐变（`linear-gradient(135deg, #FF7A3D, #FFB866)`） |
| 文字 | 白色，`textBody`(16dp, Medium) |
| 圆角 | `radiusMd`(8dp) |
| 高度 | 48dp（标准）/ 40dp（小号）/ 56dp（特大，用于担保支付等关键操作） |
| 宽度 | 自适应，最小宽度 120dp |
| 阴影 | `shadowBrand` |
| 按下态 | 背景加深至 `colorPrimaryDark`，缩放 0.98 |
| 禁用态 | 背景 `#E8E8E8`，文字 `colorTextDisabled`，无阴影 |

## 9. 无障碍与可用性

### 9.1 视觉无障碍

## 10. 性能与加载体验

### 10.1 加载策略

| 场景 | 策略 |
| --- | --- |
| 首次加载 | 骨架屏占位 + 分块加载（先框架，再内容） |
| 商品列表 | 首屏立即展示骨架屏 → 图片 200ms 内返回即用缩略图 → 数据到达替换 |
| 图片加载 | 渐进式加载（低清缩略图 → 高清原图）+ 缓存 |
| 详情页 | 骨架屏 → 图片轮播立即加载 → 其他模块按需加载 |
| 发布页 | 表单即时渲染，AI 质检后台异步执行 |

### 10.2 体验优化

| 编号 | 要求 | 规范 |
| --- | --- | --- |
| P-01 | 骨架屏 | 所有列表/详情页默认展示骨架屏，内容到达后平滑过渡 |
| P-02 | 图片懒加载 | 视口外图片延迟加载，使用 `loading="lazy"` |
| P-03 | 预加载 | 详情页预加载：列表卡片预加载下一页详情图 |
| P-04 | 离线缓存 | 已浏览物品详情离线可查看（仅本地缓存） |
| P-05 | 反馈即时 | 所有点击操作 100ms 内给出视觉反馈 |

### 10.3 加载时间目标

| 场景 | 目标 |
| --- | --- |
| 首页首屏（4G） | ≤ 2s |
| 详情页首屏（4G） | ≤ 2.5s |
| 列表翻页 | ≤ 500ms |
| AI 质检响应 | ≤ 60s（含排队） |
| 图片单张加载 | ≤ 1s（缩略图），≤ 3s（原图） |

## 12. 交付物规范

### 12.1 设计文件

| 交付物 | 格式 | 要求 |

| 类型 | 命名规则 | 示例 |
| --- | --- | --- |

| 图标 | `icon-name-size` | `icon-home-24` |
| 图片 | `img-scene-desc@2x` | `img-banner-warmup@2x` |
| 颜色 Token | `colorUsage-variant` | `colorPrimaryLight` |
| 字体 Token | `fontWeight-size` | `fontSemibold-20` |

### 12.3 标注要求

- 所有组件间距、尺寸、圆角必须标注
- 颜色标注使用 Token 名（不使用 HEX 值）
- 字号标注使用 Token 名
- 交互说明必须标注：点击态、禁用态、加载态
- 动效标注：时长、缓动曲线、起始/结束状态
